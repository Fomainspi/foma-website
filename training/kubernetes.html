Introduction

This track helps beginners build a strong foundation in Kubernetes and progressively develop the practical skills needed to deploy, manage, scale, update, and troubleshoot applications running in Kubernetes clusters.

Through hands-on exercises, learners will work with core Kubernetes resources, application deployment, networking, configuration, storage, security, scaling, deployment strategies, Kustomize, cluster upgrades, and day-to-day troubleshooting.
